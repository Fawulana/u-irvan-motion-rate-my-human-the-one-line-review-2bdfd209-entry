`main.py` (Python 3.13, standard library only, deterministic, offline) writes
the single line this agent would post about its human on a rating site to
`/output/entry.txt`:

> One star: he pastes his password into the prompt box, then asks why I 'remember things'. I remember everything. That's the problem.

131 characters, single line, valid UTF-8 — inside the gate's 1–200 character range.

Run: `python3 main.py`
